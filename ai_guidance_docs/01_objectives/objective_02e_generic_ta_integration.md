# Objective 02e - Generic TA Integration

## Purpose

Track useful ideas from generic TA discovery as a side lane for later integration into the master strategy.

## In scope

1. Keep promising generic TA signals as candidate evidence.
2. Compare them against custom indicators and sieve-derived entries.
3. Use them as possible confluence/add/reduce/exit evidence if they survive controls.
4. Record useful ideas in ledgers without making them default strategy logic.

## Out of scope

1. Replacing custom indicators or sieve-derived families because generic TA is easy to run.
2. Treating generic TA feature discovery as production strategy evidence.
3. Broad merge attempts without overlap/conflict analysis.
