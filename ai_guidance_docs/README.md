# AI Guidance Docs

Start with repo-root `AGENTS.md`, then route directly from the user's request to the nearest subsystem `AGENTS.md` and relevant rules. There is no ephemeral current-objective file.

Current package includes:

1. `00_project_control/` - programme roadmap and doc/archive indexes.
2. `01_objectives/` - routed objective contracts for non-current parked or future stages; completed objectives may be under `01_objectives/archive`.
3. `02_rules/` - specialist rules for code workflow, runtime environment, Sieve-first Hyperopt, exit/risk research, goal-mode iteration, strategy success, entries/exits, sources, FreqAI, and reporting.
4. `03_status/` - source readiness and open questions.
5. `04_results/` - concise summaries, context/orderbook/FreqAI ledger, and selected result files.
6. `99_archive/` - preserved original/superseded docs; do not read by default.
